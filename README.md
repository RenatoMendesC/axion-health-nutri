# AXION HEALTH NUTRI

Vitrine independente de suplementos Black Skull — use o cupom **AXION10** na loja oficial para obter 10% de desconto em compras elegíveis, conforme regras do programa.

## Hospedagem

Este projeto é um site estático HTML/CSS/JavaScript, hospedável em **Render Static Site** sem hibernação por inatividade. Não use o tipo "Web Service" gratuito, que pode suspender após inatividade.

**Render**
- Repositório: `https://github.com/RenatoMendesC/axion-health-nutri`
- Branch: `main`
- Tipo: `Static Site`
- Build Command: `mkdir -p public && cp index.html public/index.html`
- Publish Directory: `public`
- Auto deploy: habilitado

A configuração opcional para Blueprint está em `render.yaml`.

A AXION HEALTH NUTRI é uma vitrine independente/afiliada. Compras e pagamentos são processados no site oficial da Black Skull. Não existe checkout próprio.
